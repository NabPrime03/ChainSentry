# CryptoTrace Frontend (Client)

This directory is reserved for the frontend team (React / Next.js / Vue).

## Backend Integration Details
- **API Base URL:** `http://localhost:8000`
- **Interactive API Documentation:** `http://localhost:8000/docs`
- **Trace Endpoint:** `POST http://localhost:8000/api/v1/trace`
- **Embedded Graph View:** `GET http://localhost:8000/api/v1/graph/html?address={address}`
- **Full Architecture & Integration Specs:** See `../docs/architecture.md`
